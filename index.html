Install Celou App

Home-screen launch, full screen & fast offline access

Google Chrome (Mobile & Tablet)

Recommended
  1. Tap the three dots menu (⋮) at the top right of Chrome (or look for the Install App icon in the address bar).
  2. Select "Install app" or "Add to Home screen".
  3. Tap Install when prompted to add Celou to your app drawer and home screen.

Tip: If you are using Chrome inside an in-app browser (e.g. Facebook, Gmail), tap the 3 dots and choose "Open in Chrome" first.

iPhone & iPad (Safari / Chrome)

  1. Tap the Share button in the browser navigation bar.
  2. Scroll down and select "Add to Home Screen" .
  3. Tap Add in the top right corner.

Google Chrome on Desktop (Windows / Mac)

  1. Look for the Install icon (monitor with arrow) on the right side of the address bar. Click it and choose Install.
  2. Or open the Chrome menu (⋮) → Save and share → Install Celou Rental Property…
  3. Confirm the install. The app will open in its own window.

If the install option is missing, refresh the page once (after the site loads fully) and try again. The site must be opened over HTTPS.
